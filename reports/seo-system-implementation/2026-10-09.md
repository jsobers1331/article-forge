## Validation

The untouched refreshed-main baseline passed **224 pytest tests**. Before fixes,
**11 new targeted regressions failed**, reproducing the audited ledger, score
and SERP bypasses. The implementation passes **374 pytest tests**, Ruff lint,
CI's exact three-file formatting check, Python compilation and diff checks.
Tests use fresh temporary configs/source files/ledgers and stubbed providers.
They do not borrow owner credentials or treat synthetic results as live proof.

Independent review of the initial integration revision found four additional
edge cases, reproduced by a separate skeptic and corrected before merge:
local CRLF/invalid-UTF-8 sources now bind the acquired original bytes; all
consumed metric counts reject negative, boolean and nonfinite values; each
access/index observation requires its own current timezone-aware date; and
publication versions are ordered by actual instants. The review added 31 tests.
The original pushed implementation and initial integration commits remain
preserved locally; the corrected integration is prepared separately in
`/private/tmp/article-forge-seo-reviewed-20261009`.

## Migration and practical limits

Read [EVIDENCE_SYSTEM.md](../../EVIDENCE_SYSTEM.md) for schemas and commands.
Legacy ledgers must be reverified against their real sources. Legacy snapshots
must be recollected or migrated with authentic timestamps, locale, source text
and reviewed extraction. No metadata date refresh substitutes for verification.
Initial drafts normally remain quarantined until the exact manifest is reviewed;
`--review-draft` rechecks them locally without another writer call. Reports now
use v2 and may contain null scores; numeric-only downstream consumers must adapt.
The local registry CLI uses filesystem locks on macOS/Linux and requires explicit
paths. GSC export locale granularity is retained separately from publication locale.

Deterministic checks do not prove source authority, semantic truth, usefulness,
originality or legal meaning. The material-assertion heuristic can miss implied
or context-dependent claims; whole-draft human review remains required. Fresh
remote snapshots can be reused inside the configured window without proving
the remote page has not changed; suspected changes require forced re-verification.

The original photography case study remains historical evidence. No new live
traffic/conversion data, causal benchmark or future 30/60/90-day measurement is
claimed. Those require later owner-authorized publishing and measured cohorts.
